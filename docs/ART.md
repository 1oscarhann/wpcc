# Art, audio and feel

> **Decided (Phase 2):** top-down 3/4 pixel art, and **every visual asset is original**. All of it is generated by our own code in `tools/artgen/`. No third-party art packs. See D-001 and D-031.

## 1. Rules

| Rule | Value |
|---|---|
| Perspective | Top-down 3/4: front-facing buildings, 3-direction characters (right is a mirror of left) |
| Base pixel scale | **16×16 px per tile**, never mixed. Characters are 16×24 frames. |
| Display scale | Integer zoom only at rest: 2× (Build overview), 3× (default), 4× (close). Non-integer only mid-tween. |
| Filtering | Nearest-neighbour everywhere, `roundPixels: true`, 2 px atlas padding with edge extrusion |
| Lighting | Key light from the **top-left**. Highlights go on top/left edges, shade on bottom/right, plus a soft drop shadow under every standing object. The generator applies this in one place (`shade.py`), so it can't drift. |
| Outline | 1 px dark outline (`ink`, a warm near-black, never pure `#000`) on every object sprite. Terrain tiles have no outline. |
| Palette | One master palette in `tools/artgen/palette.py`. Every sprite only uses palette colours, which `validate.py` checks. |
| Rarity colours | grey `#9aa0a6`, green `#4caf50`, blue `#3d8bfd`, purple `#a259ff`, orange `#ff9f1c`. These are UI tokens and glow tints, used everywhere. |

## 2. How the art is made

`tools/artgen/` is a deterministic Python and Pillow program. The same seed always gives byte-identical PNGs. Run it with:

```
uv run --project tools/artgen python -m artgen
```

It writes `frontend/src/assets/gen/*.png` (atlases), `frontend/src/assets/gen/atlas.json` (frame rects), and the logical-name entries in `frontend/src/assets/manifest.json`.

| Module | Makes |
|---|---|
| `palette.py` | Master palette, named ramps (grass, dirt, stone, wood, roof_red, roof_blue, water, skin×6, hair×10, cloth×12, ui) |
| `shade.py` | Drawing helpers: outlined shapes, top-left lighting, dithering, drop shadows, mirrored frames |
| `terrain.py` | Grass variants, flowers, tilled soil, dirt path **autotiles** (16 cardinal masks), water with shore autotiles, cobblestone (hub), plot-edge markers |
| `nature.py` | Trees (oak, pine, bushy, 2 sizes), bushes, rocks, stumps, tall grass, flowers |
| `buildings.py` | One function per building, composed from parts (walls: planks/stone/plaster; roofs: gable/thatch/slate; door, windows, chimney, signs and props). Includes the **level overlay kit** (L2–L5 adornments), **construction scaffold** per footprint, and dust-puff frames. |
| `characters.py` | **Layered** avatar and villager parts: 2 body types, 6 hair styles, 4 eye styles, 6 outfits. Every part is drawn in *shade-index* colours that the client recolours at runtime (skin, hair, eyes, outfit colour), so the character creator is truly layered. Frames: idle ×2 and walk ×4, for down, up and side. |
| `creatures.py` | Monsters with squash-and-stretch frames (slime, wolf, spider: idle, move, wind-up, attack, hurt), the elite crown, held weapons (sword, spear), slash arcs, hit sparks and death poofs |
| `icons.py` | 16×16 icons: every resource, coins, and UI actions (build, upgrade, move, rotate, demolish, undo, close, settings, sound, timer, lock) |
| `ui.py` | 9-slice parchment panel, wood frame, buttons (normal/hover/pressed/disabled), slot, tooltip, progress bar, tab |
| `validate.py` | Palette-only check, frame size checks, deterministic-output check (used in CI) |

**Fonts** are the only non-generated visual assets: *Pixelify Sans* (headings) and *Fredoka* (body), both SIL OFL 1.1, self-hosted. They're listed in `CREDITS.md`.

**Audio** is synthesized at runtime with WebAudio (`frontend/src/game/sfx.ts`, D-047): oscillators and filtered noise for swings, chops, pickups, hits, crits, squishes, growls and level-ups. It's original and costs nothing to download. Music and ambience come in later phases.

## 3. Building visuals

| Need | Approach |
|---|---|
| Building level 1–5 art | Base sprite plus a **level overlay kit**: L2 pennant, L3 stone foundation and window boxes, L4 banners and roof trim, L5 gold trim plus a sparkle. Composed at runtime: `building.<key>` + `overlay.l<n>.<w>x<h>`. |
| Construction | A scaffold sprite per footprint size, a progress bar and a countdown above it |
| Rotation (P6) | Horizontal mirror plus footprint swap for non-square buildings |
| Pop-in juice | Squash and stretch (GSAP) plus dust-puff particles from `fx.dust` |

## 4. Asset manifest

`frontend/src/assets/manifest.json` is the only way code references art. Logical names (`building.forge`, `tile.grass.0`, `icon.wood`, `char.hair.3.walk.down`) are stable, so regenerating or hand-replacing art never touches game code.
